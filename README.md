# Ankit Jha — Portfolio

Personal portfolio site for Ankit Jha, a climate policy professional based in New Delhi, India, working on climate resilience, governance and locally-led climate action.

Live at **[ankit-jh.github.io](https://ankit-jh.github.io/)**.

## Stack

Plain HTML, CSS and JavaScript — no build step, no framework. Served directly by GitHub Pages from the `main` branch.

- `index.html` — page structure and content
- `styles.css` — styling, theming (light/dark), layout
- `script.js` — interactivity: scroll reveals, theme toggle, publication filters, hero canvas animation, mobile nav
- `ajresume.pdf` — downloadable résumé (linked from the nav)

## Local development

No build tools required — just open `index.html` in a browser, or serve the folder with any static file server, e.g.:

```bash
python -m http.server 8000
```

## Deployment

Pushes to `main` publish automatically via GitHub Pages.
